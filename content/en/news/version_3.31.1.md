Streaming.Center version 3.31.1 is out:

- Fixed bugs found after the major 3.31.0 release.
- Optimized database queries and indexes for better performance.
- Added Ubuntu 26.04 support.
- Fixed scheduling conflicts and rotation ordering.
- Improved the calendar view and made dense schedules much faster to load.
- Reduced AutoDJ CPU usage by about 10%.
- Made LoudGain file processing up to 2× faster on modern CPUs.
- Improved audio processing with better clipping protection.
- Improved stream stability when a Shoutcast output disconnects or stalls.
