Version 3.31.0 is out:
- Added [Shoutcast v2 support](/docs/platform/shoutcast2/) for live DJ streams, including track cover artwork.
- Added [sequential rotations](/docs/platform/rotations/).
- Added [clock rotations](/docs/platform/rotations/).
- Added FTP upload quotas.
- Upgraded the web interface to use modern UI libraries.
- Upgraded Stereo Tool from version 10.30 to 11.01.
- Added optional two-factor authentication (2FA) for broadcaster accounts.
- Introduced numerous minor updates and improvements.
